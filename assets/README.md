# Assets Directory

Reusable assets, templates, and resources for the branch-validation-wordpress skill.

## Contents

This directory contains static assets and templates used by the skill:

- **Templates** — PR templates, commit templates, changelog templates
- **Icons** — SVG icons for branch types and status indicators
- **Checklists** — HTML/Markdown checklists for release workflows
- **Examples** — Example files and configurations

## Usage

Assets in this directory are referenced by:
- Skill documentation files
- Sub-skill guides
- Testing templates
- Release workflows

## Guidelines

When adding new assets:
1. Use clear, descriptive filenames
2. Include a brief comment/description
3. Organize by type (templates/, icons/, etc.)
4. Update this README with new additions
5. Commit assets to version control
